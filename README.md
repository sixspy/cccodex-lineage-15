# cc-lineage-lab

CC_Codex 二期（26.11）**数据工程**产品线：**表血缘影响台**（Bottle + Waitress + 原生 JS SPA + SQLite）。

## 一句话骨架

**血缘节点 → 边关系 → 影响分析作业 → 下游通知 → 覆盖对账**

与压实/回灌/契约线正交；不碰外仓常见指纹。

## 领域

- **所属领域**：数据工程
- **子方向偏分析**：表血缘登记、影响分析、下游通知、覆盖核对

## 页面（≥5）

1. 节点目录 2. 边关系 3. 边依赖附页 4. 修订隔离 5. 影响分析 6. 下游通知 7. 覆盖对账 8. 台参数

## 目录修订隔离

- 工程落点唯一：**独立账册**写隔离凭证并记下目录指纹供核齐（不建影子草稿表，两种安置不可并存）。
- 开窗一次事务写入（`BEGIN IMMEDIATE` 串行闸 + 开窗范围唯一索引），两名仓管抢开同一范围不会双写凭证。
- 影响分析按台参数「隔离口径」跳过窗内节点：严格=断边，宽松=穿边不记命中；页面给出已隔离节点数。
- 清洗调度入库核目录指纹，与隔离窗拧了就拦住。
